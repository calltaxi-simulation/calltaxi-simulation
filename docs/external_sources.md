# 코드 밖 근거

이 저장소의 코드로 재현되지 않는 근거를 모은 문서다. 문헌·구술 자료, 코드 밖에서
수행돼 사후에 정리한 기록(소급 기록), 받지 못한 자료의 사유, 그리고 저장소 밖에 있는
스크립트가 여기 들어간다.

**코드로 재현되는 것은 여기 없다** — 필터 정의·지표 정의·산출 방식은
[`calibration.md`](calibration.md), 산출된 값은 [`provenance.md`](provenance.md) 에 있다.
**가정 부호(A-xx)의 정의도 여기 없다** — [`assa_log.md`](assa_log.md) 가 정본이다.

결과물과 작업자 진술을 바탕으로 사후 정리했으므로 건수·기준의 근거 강도가 다르다.

그중 하나는 이후 근거가 확보됐다 — **B-3 은 `src/idle.py` 로 재현된다.**
나머지 6건은 여전히 재현 경로가 없다.

> **아래 값은 원문 그대로 두었다.**

| 항목 | 내용 |
|---|---|
| 대상 데이터 | `서울시설공단_장애인콜택시 탑승내역_20251231.csv` 원본 1,729,476행(필터 없음) |
| 가공 내용 | 일별 콜 수를 결측일 보간 후 STL 분해(`period=7`, robust), 정상성 검정, 요일·시간대 분포 |
| 산출물 위치 | 저장소 밖 노트북. **재현 경로가 없다** |

**당시 확인된 결과** — 이 둘만 A-03 의 근거로 살아 있다.

| 내용 | 결과 |
|---|---|
| STL 분해(`period=7`) | **요일 효과가 지배적** — 평일 +700 ↔ 주말 −2,000, 진폭 2,500 이상. 추세는 연중 안정 |
| 정상성 검정 | ADF p = 0.00018 · KPSS p = 0.1 → **정상, 차분 불필요** |

**요일 효과 ≠ 연중 계절성.** `period=7` 은 요일 주기를 잡으므로 A-03 의 "연중 계절성
없음"과 모순되지 않는다 — 오히려 요일 효과가 크다는 사실이 대표 기간 재생을
뒷받침한다(어느 구간을 골라도 요일 구성이 같아 상쇄된다). 자세한 것은 A-03.

**한계** — 노트북이 저장소 밖이고 입력 경로도 작성자 로컬이라 **재현할 수 없다.**
그 전수에는 임차택시가 섞여 있어(A-16) 지금 모집단과 더 벌어졌다. 시계열 분해는
`src/*` 에 반영돼 있지 않다.
