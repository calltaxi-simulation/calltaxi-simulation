# 산출된 값 (provenance)

이 저장소의 스크립트를 그대로 돌려 얻은 **현재 값의 대장**이다. 어느 함수가 어떤 값을
내는지 확인하거나, 코드를 고친 뒤 값이 움직였는지 대조할 때 쓴다.

값의 **정의·필터·근거**는 [calibration.md](calibration.md) 에 있다. 이 문서는 정의를
다시 설명하지 않고 결과만 싣는다. 코드 밖 근거는 [external_sources.md](external_sources.md).

**재현 방법**

```bash
cd simulation
.venv\Scripts\python.exe src/load.py          # 데이터 로딩·필터·좌표매칭 요약
.venv\Scripts\python.exe src/travel_time.py   # 이동시간 테이블·커버율·오차
.venv\Scripts\python.exe src/metrics.py       # 동별 지표 산출 + 검증 6개 대조
.venv\Scripts\python.exe src/idle.py          # 유휴 구간 건수·분포·시간대별 동시 유휴
.venv\Scripts\python.exe src/candidates.py    # 동별 후보 배정(규칙별 동 수·보류 목록)
```

실행 환경은 `simulation/.venv` 다(전역 파이썬 아님). 검증된 버전 조합은
[README](../README.md#환경-설정) 참조.

데이터 폴더는 `load.resolve_data_dir()` 이 정한다 — 환경변수 `DATA_DIR` 이 있으면
그쪽, 없으면 저장소 상위의 `../data/`.

## 12. 시뮬레이터

`src/simulator.py` 는 **뼈대만 있고 구현되지 않았다**(`raise NotImplementedError`).
따라서 **before/after 비교값·배치안 평가 결과는 아직 산출된 것이 없다.**

위 수치의 성격은 두 갈래다.

| 갈래 | 해당 | 성격 |
|---|---|---|
| **실측 집계값** | 1~9절 | 원본을 필터·집계해 센 값. 같은 원본이면 같은 값이 나온다 |
| **실측에서 추정한 값** | **10절 인내심 곡선** | 관측(포기 104,434 · 절단 138.4만)에 Kaplan-Meier 를 적용한 **추정치**다. 표본에 딸린 불확실성이 있고 꼬리는 특히 얇다(중앙 211분 지점의 위험집합 141건) |

**시뮬 산출값은 아직 없다.** 10절을 시뮬 결과로 읽지 말 것 — 그것은 시뮬의 **입력**이다.

`src/dashboard.py` 는 구현돼 있으나 **실측 지표를 보여줄 뿐 새 값을 만들지 않는다**
(입력은 `outputs/dong_metrics.csv` 등). 화면 결정은
[dashboard_spec.md](dashboard_spec.md) 참조.

정의된 상수만 있다: `SEED = 42`, `DISPATCH_RADIUS_DAY = 7km`,
`DISPATCH_RADIUS_NIGHT = 12km`(자동배차 탐색 반경 — 출처 확인 필요, 미확정).
